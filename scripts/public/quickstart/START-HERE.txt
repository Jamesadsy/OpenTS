CnC TS for iPhone/iPad — Public Test 055 Quickstart

This package contains the public preparation helper and a Windows launcher.
It contains no Tiberian Sun or Firestorm game data.

1. Get Tiberian Sun and Firestorm game data from a lawful source.

   Free community source:
   CnCNet how-to: https://cncnet.org/tiberian-sun/how-to-play
   C&C Communications Centre installer:
   https://cnc-comm.com/tiberian-sun/downloads/the-game/installer

   These pages describe Tiberian Sun / Firestorm as freeware released by
   Electronic Arts in 2010. In the community installer, include the campaign,
   music and movie components for the complete iOS experience.

   Lawful retail alternatives:
   Steam: https://store.steampowered.com/bundle/39394/
   EA App: https://www.ea.com/games/command-and-conquer/command-and-conquer-the-ultimate-collection

   The C&C community installer's output was not directly tested for this
   release. When prompted, select the installed Tiberian Sun / Firestorm folder
   that contains the game files. The helper copies files recursively from that
   folder and its subfolders.

2. Download OpenTS-unsigned.ipa and CnC-TS-iOS-Quickstart.zip from the Public
   Test 055 release:
   https://github.com/Jamesadsy/OpenTS/releases/tag/cnc-ts-ios-preview-055

3. Extract this ZIP. Double-click Prepare-CnC-TS-iOS.cmd. Paste or drag the
   installed game folder path and downloaded IPA path into the prompts. Press
   Enter at the output prompt to use your Documents folder.

   The default output is:
   Documents\CnC-TS-iOS-Ready\OpenTS\Data
   Documents\CnC-TS-iOS-Ready\OpenTS\User

   The helper verifies the exact Public Test 055 IPA before it writes output.
   It does not change the IPA or your game installation. A non-empty output
   folder is protected from overwrite.

4. Sign and sideload the unchanged IPA with Sideloadly or SideStore. Use their
   current setup instructions:
   Sideloadly: https://sideloadly.io/
   SideStore: https://docs.sidestore.io/docs/installation/install

5. Launch CnC TS once, then close it. In Files, copy the generated OpenTS
   folder into the CnC TS app's Documents area. The final paths are:
   CnC TS\OpenTS\Data
   CnC TS\OpenTS\User

6. Launch CnC TS and play. See IOS_INSTALL.md in the repository for detailed
   setup, transfer, save and troubleshooting instructions.

Keep original game data private. Do not upload it to GitHub or send it in bug
reports. The release distributes the engine and preparation helper only.
